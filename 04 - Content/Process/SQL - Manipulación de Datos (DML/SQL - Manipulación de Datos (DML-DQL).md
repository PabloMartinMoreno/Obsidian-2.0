# SQL - Manipulación de Datos (DML/DQL)

***

## Cheatsheet

| **Comando**                                   | **Descripción**                                      |
| --------------------------------------------- | ---------------------------------------------------- |
| `SELECT * FROM table_name;`                   | Muestra todas las columnas.                          |
| `SELECT col1, col2 FROM table;`               | Muestra columnas específicas.                        |
| `INSERT INTO table VALUES (val1,..);`         | Inserta valores.                                     |
| `UPDATE table SET col1=val1 WHERE <cond>;`    | Actualiza valores existentes.                        |
| `SELECT * FROM table ORDER BY col1;`          | Ordena resultados.                                   |
| `SELECT * FROM table ORDER BY col1 DESC;`     | Orden descendente.                                   |
| `SELECT * FROM table LIMIT 1, 2;`             | Muestra 2 resultados saltando el primero (offset 1). |
| `SELECT * FROM table WHERE name LIKE 'adm%';` | Buscar por patrón (wildcard).                        |
