# Transferencia de Archivos

***

## 🖥 OS-Specific Transfer Methods
  Técnicas nativas de cada sistema operativo para mover archivos.

   - [[Windows File Transfer Methods]] (Uso de PowerShell, CertUtil, SMB, etc., para transferencias en entornos Windows.)
   - [[Linux File Transfer Methods]] (Uso de wget, curl, scp, nc, etc., para transferencias en entornos Linux.)

## ⌨ Code-Based & Manual Transfers
  Métodos que no dependen de herramientas estándar del sistema, usando lenguajes de scripting o input manual.

   - [[Transferring Files with Code]] (Creación de downloaders usando Python, Perl, Ruby, PHP, etc.)
   - [[Miscellaneous File Transfer Methods]] (Técnicas variadas y menos comunes para mover datos.)

## 🌾 Living off The Land (LOLBins)
  Uso de binarios legítimos presentes en el sistema para realizar transferencias.

   - [[Living off The Land Transfers]] (Aprovechamiento de herramientas administrativas preinstaladas para descarga de archivos.)
