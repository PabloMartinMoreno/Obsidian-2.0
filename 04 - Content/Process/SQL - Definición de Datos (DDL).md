# SQL - Definición de Datos (DDL) 

***

## Cheatsheet

| **Comando**                                    | **Descripción**                         |
| ---------------------------------------------- | --------------------------------------- |
| `SHOW TABLES;`                                 | Lista tablas en la DB actual.           |
| `DESCRIBE logins;`                             | Ve columnas y propiedades de una tabla. |
| `CREATE TABLE logins (id INT, ...);`           | Crea una tabla nueva.                   |
| `DROP TABLE logins;`                           | Elimina una tabla.                      |
| `ALTER TABLE logins ADD newCol INT;`           | Agrega una columna nueva.               |
| `ALTER TABLE logins RENAME COLUMN old TO new;` | Renombra una columna.                   |
| `ALTER TABLE logins MODIFY col DATE;`          | Cambia el tipo de dato de una columna.  |
| `ALTER TABLE logins DROP col;`                 | Elimina una columna.                    |
