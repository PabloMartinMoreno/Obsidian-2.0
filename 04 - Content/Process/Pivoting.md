# Pivoting

***
## 🗺 Reconnaissance for Pivoting
 Identificación de nuevos objetivos y rutas accesibles desde el sistema comprometido.

  - [[Pivoting Reconnaissance]] (Técnicas de enumeración desde el host pivote para descubrir redes internas y sistemas inalcanzables directamente.)

## Port Forwarding Techniques
 Redirección de tráfico de red para acceder a servicios en redes aisladas.

  - [[Local Port Forwarding]] (Reenvío de un puerto remoto a un puerto local a través del túnel.)
  - [[Dynamic Port Forwarding]] (Creación de un proxy SOCKS a través del túnel para acceder a múltiples servicios.)
  - [[Reverse Port Forwarding]] (Reenvío de un puerto local del atacante a un puerto en el host pivote.)

## 🔗 Proxy Chaining & Tunneling
 Encadenamiento de proxies para ocultar el origen o acceder a redes segmentadas.

  - [[Proxy Chaining]] (Conexión de múltiples proxies o túneles para enmascarar la ruta de ataque.)
