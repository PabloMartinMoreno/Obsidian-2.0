# nslookup

---

## Cheatsheet

| **Comando**                                           | **Descripción**                                                    |
| ----------------------------------------------------- | ------------------------------------------------------------------ |
| <pre><code>`nslookup $TARGET`</code></pre>            | <br>Identifica el registro **A** del dominio objetivo.             |
| <pre><code>`nslookup -query=A $TARGET`</code></pre>   | <br><br>Identifica el registro **A** del dominio objetivo.         |
| <pre><code>`nslookup -query=PTR <IP>`</code></pre>    | <br>Identifica el registro **PTR** de la dirección IP objetivo.    |
| <pre><code>`nslookup -query=ANY $TARGET`</code></pre> | <br>Identifica **todos los registros (ANY)** del dominio objetivo. |
| <pre><code>`nslookup -query=TXT $TARGET`</code></pre> | <br>Identifica los registros **TXT** del dominio objetivo.         |
| <pre><code>`nslookup -query=MX $TARGET`</code></pre>  | <br>Identifica los registros **MX** del dominio objetivo.          |
