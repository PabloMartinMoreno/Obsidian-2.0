# Social Engineering Assets

***

## 📄 Weaponized Documents
  Documentos ofimáticos diseñados para ejecutar código al abrirse.

   - [[Creating Malicious Office Macros]] (Desarrollo de VBA macros para Word/Excel que descargan y ejecutan malware.)
   - [[OLE Object Embedding]] (Incrustación de objetos ejecutables dentro de documentos.)
   - [[HTML Smuggling]] (Uso de HTML5/JS para construir el archivo malicioso directamente en el navegador de la víctima.)

## 📧 Delivery Infrastructure
  Infraestructura necesaria para enviar los correos de phishing.

   - [[Setting up Phishing Domains]] (Configuración de DNS, SPF, DKIM y DMARC para mejorar la reputación del correo.)
   - [[Email Spoofing Techniques]] (Técnicas para falsificar remitentes cuando no hay protección.)

## 🎣 Web Deliveries
  Sitios web maliciosos o clonados.

   - [[Cloning Login Portals]] (Creación de páginas de login falsas para robo de credenciales.)
   - [[HTA & Web Payloads]] (Uso de aplicaciones HTML (.hta) para ejecución de código vía web.)
