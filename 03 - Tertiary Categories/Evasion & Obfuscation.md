# Evasion & Obfuscation

***

## 🛡 Static Analysis Evasion
  Técnicas para evadir la detección basada en firmas de archivos.

   - [[Modifying Exploit Signatures]] (Cambio de variables, comentarios y estructura para romper firmas conocidas.)
   - [[Encoding & Encryption]] (Uso de codificadores (Shikata Ga Nai) o cifrado (AES/XOR) para ocultar el payload.)
   - [[Using Packers & Crypters]] (Herramientas que comprimen o cifran el ejecutable final para ocultar su contenido.)

## 🎭 Script Obfuscation
  Hacer ilegible el código interpretado para bypass de filtros y loggin.

   - [[Obfuscating PowerShell Scripts]] (Técnicas como cambio de mayúsculas/minúsculas, backticks y ofuscadores automáticos.)
   - [[Obfuscating Bash & Python]] (Métodos para esconder la intención de scripts en Linux.)

## 🏃 Dynamic Analysis Evasion
  Técnicas para detectar si estamos en un entorno de análisis (Sandbox) y no ejecutarse.

   - [[Sandbox Detection Techniques]] (Verificar dominio, memoria RAM, movimientos del ratón o tiempo de actividad.)
   - [[AMSI Bypass]] (Métodos para deshabilitar el Antimalware Scan Interface en Windows.)
